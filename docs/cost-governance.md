# Cost governance

Example allocation dimensions are Environment, Application, Owner and CostCenter. Define owners, standard values, propagation policy and treatment of shared services. Activate cost allocation tags in the account before relying on them; example tags in this repository do not imply account configuration.

Set AWS Budgets to notify owners at agreed forecast/actual thresholds. Cost Explorer supports cost and usage exploration; Compute Optimizer and Cost Optimization Hub can surface opportunities where enabled. These services are not integrated with this sample tool.

Review budgets and anomalies with workload context. Separate one-time migration expense, shared platform cost, commitments, credits and traffic volume. Assign review cadence and remediation owners. A budget alert signals investigation, not automatic permission to remove capacity or security controls.
