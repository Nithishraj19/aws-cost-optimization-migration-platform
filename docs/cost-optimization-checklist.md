# Cost optimization checklist

- [ ] Compute: idle capacity, utilization peaks, memory, I/O, autoscaling, schedules, rightsizing and Graviton compatibility.
- [ ] Containers: optimize images; measure size; retain rollback tags.
- [ ] Network: attribute NAT, ALB/NLB, egress and cross-AZ; preserve security and availability.
- [ ] Storage: EBS sizing/IOPS, snapshots, S3 lifecycle and restore tests.
- [ ] Observability: log ingestion, retention, metric cardinality and queries; retain needed evidence.
- [ ] Architecture: compare EKS, EC2/Docker, Lambda, queues and managed services by workload fit and total cost.
- [ ] Governance: owned tags, budgets, alerts, allocation and regular reviews.
